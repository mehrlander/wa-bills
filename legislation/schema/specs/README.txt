WA Legislative Web Services - Technical Specifications
Downloaded: 2026-01-02T19:00:56.016Z

This archive contains:
- WSDL files for all 9 web services
- WebServiceDataDictionary.doc (field definitions)

Services included:
- LegislationService
- CommitteeService
- CommitteeActionService
- CommitteeMeetingService
- LegislativeDocumentService
- SessionLawService
- SponsorService
- AmendmentService
- RcwCiteAffectedService

Source: https://wslwebservices.leg.wa.gov/

To use WSDL files:
1. Open in any XML viewer or WSDL parser
2. Use with SOAP client tools (SoapUI, Postman, etc.)
3. Parse programmatically with libraries like Python's zeep or suds

For more information:
- Main page: https://wslwebservices.leg.wa.gov/
- Details: https://wslwebservices.leg.wa.gov/lwsDetails.htm
- Contact: WebRequest@leg.wa.gov
