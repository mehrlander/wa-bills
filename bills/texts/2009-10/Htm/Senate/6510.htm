     AN ACT Relating to the extension of state route number 166; amending RCW 47.17.328; and creating a new section.

BE IT ENACTED BY THE LEGISLATURE OF THE STATE OF WASHINGTON:

NEW SECTION.  Sec. 1   It is the intent of the legislature that state route number 166 be extended to serve as an alternate state route connection between state route number 16 and the Southworth state ferry dock.

Sec. 2   RCW 47.17.328 and 1993 c 430 s 3 are each amended to read as follows:
     A state highway to be known as state route number 166 is established as follows:
     Beginning at a junction with state route number 16 in the vicinity west of Port Orchard, thence ((northeasterly to the eastern Port Orchard city limits)) easterly via Port Orchard to the Washington state ferry dock at Point Southworth.
