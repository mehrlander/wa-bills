# Documentation-Claims Audit: `wa-bills`

**Date:** 2026-07-18
**Repository:** `/home/user/wa-bills` (Washington State legislation data archive)

## Method

An agent pyramid decomposed 52 documentation files into 1,966 individual claims. Of these, 1,621 verified clean against the working tree, 171 were unverifiable (external links, provenance statements, leg.wa.gov behavior), and 173 were reported as discrepancies. An adversarial skeptic pass re-measured each reported discrepancy independently; it refuted 8 and let 165 stand. Every surviving finding carries a verdict: `confirmed` (independently re-measured, 161 findings) or `adjusted` (the discrepancy holds but a detail was corrected, 4 findings). No finding remains `unreviewed`; the skeptic pass matched all 165. A final hand pass then spot-checked a sample spanning the major groups (the missing `docs/` path, the project counts, the 1999-00 index gap, the 18-biennium re-pull, the study `raw/` layout, the Bill 1125 example, the regular-expression cap); each sampled finding reproduced.

This report records findings as measured on 2026-07-18. The corrections were then applied in the same change: the findings below describe the pre-correction state, and the repository diff is the record of what changed. A few findings were left unfixed by deliberate choice (a code-level defect a doc edit cannot reach, or an enumeration a surgical edit cannot complete without inventing content); those are noted in the change description.

The `projects/` tree, which several groups below concern (chiefly Groups C, D, and I), was retired the next day, 2026-07-19; see [`projects-retired-2026-07.md`](projects-retired-2026-07.md). Those findings are now moot, and their links point to the pre-retirement tree in history at [`47dfded83`](https://github.com/mehrlander/wa-bills/tree/47dfded83/projects).

The `bills/studies/` tree, which Groups B and L concern, was also retired 2026-07-20 after a per-study data audit; see [`studies-retired-2026-07.md`](studies-retired-2026-07.md), which records both that audit and the retirement. Those findings are now moot, and this report's links to the studies point to the pre-retirement tree in history at [`82548b9fe`](https://github.com/mehrlander/wa-bills/tree/82548b9fe/bills/studies).

The `docs/` folder this report and Group A describe was itself retired 2026-07-20: `hierarchy.md` moved to the repository root, and this report moved with `large-files-survey.md` (renamed `large-files-survey-2026-02.md`) and `projects-retired-2026-07.md` into a new `probes/` folder for dated point-in-time surveys. Group A's finding (no `docs/` directory existed) is therefore true again, for a different reason; the links in this report have been updated to the new paths, but the prose describing the July 18 state is left as measured.
